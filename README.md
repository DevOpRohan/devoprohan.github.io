# Rohan Kumar - Portfolio

A modern portfolio website showcasing AI/ML and agentic systems work.

## 🚀 Live Site

Visit: [https://devoprohan.github.io](https://devoprohan.github.io)

## 🎨 Features

- **Dark Mode Glassmorphism Design** - Modern aesthetic with gradient orbs and blur effects
- **Smooth Animations** - Scroll-triggered animations and hover effects
- **Fully Responsive** - Works beautifully on all devices
- **Fast & Lightweight** - Pure HTML, CSS, and JavaScript

## 📁 Projects Featured

- **Vision** - LLM-controlled Vision Foundation Models for visually impaired
- **Gennie** - Local Personal AI Agent for filesystem reasoning
- **DocSphere** - Multilingual Document Intelligence with OCR

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (Intersection Observer, CSS Animations)
- Google Fonts (Inter, Outfit)

## 📦 Deployment

This site is deployed using GitHub Pages. Push to the `main` branch to deploy.
